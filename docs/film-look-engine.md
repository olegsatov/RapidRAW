# Film Look Engine — перестройка цветового ядра модуля Film

Рабочий документ. Описывает цель, подход, план и критерии приёмки перестройки
модуля симуляции плёнки. Текущее состояние модуля описано в
`docs/film-simulation.md` — этот документ заменяет часть, касающуюся цветового
ядра (`apply_film_look`), и **не затрагивает** зерно (IPOL/Pierre), галацию,
пайплайн-интеграцию и UI-каркас.

## Цель

Личный проект, **одна камера** — Sony A1 II (ILCE-1M2), 14-битный ARW. Нужен
инструмент, который из RAW выдаёт более-менее плёночную картинку — усреднённую,
не привязанную к конкретной плёнке — на **всем диапазоне входов** (экспозиция,
свет, сюжет), плюс небольшой набор бегунков для докрутки по вкусу.

## Non-goals

- Достоверное воспроизведение конкретных плёнок или химии фотопроцесса.
- Поддержка разных камер — калибруемся под одну.
- Спектральная симуляция, измерения, лаборатория.

## Диагноз: почему пресеты работают в узком диапазоне

1. **Output-referred привязка.** Пресеты (и текущий модуль) предполагают вход в
   фиксированном состоянии: серая карточка на 0.5, конкретная насыщенность.
   Отклонение входа — и кривые работают не на том участке.
2. **Двойное тон-маппирование.** Нормализация RAW-движком → затем плёночная
   кривая поверх. Нормализация уничтожает информацию о настоящих светах, и
   каждая сцена приезжает в плёночную стадию в разном состоянии.
3. **«Цифровой цвет»** — три конкретных механизма: постоянная насыщенность до
   клиппинга канала (неон, сдвиги hue в светах), жёсткий клиппинг
   вне-дисплейных цветов, отсутствие отбеливания светов и приглушения теней.

## Подход

Искажаем реальность там, где её искажали инженеры Kodak — в scene-referred
пространстве, относительно среднего серого. Без химии, но в её координатах.
Исследование prior art (см. следующий раздел) подтвердило подход и дало готовый
скелет: **ядро = адаптация flim (AGPLv3)**, а не изобретение математики с нуля.

1. **Пивот среднего серого** — авто из гистограммы + ручной EV-бегунок.
   Калибруется один раз под камеру (кадр серой карты/ColorChecker).
2. **Тон в стопах** — все операции в `log2(экспозиция / пивот)`. Кривая
   инвариантна к экспозиции по построению: ±2 стопа — это сдвиг вдоль кривой,
   а не слет с неё.
3. **Two-stage develop (из flim)** — per-channel сигмоида «negative» в
   log2-домене (toe/shoulder/density) → backlight → сигмоида «print». Даёт
   плёночное отбеливание светов, приглушение теней и кросс-канальные сдвиги
   без моделирования красителей — density-мухлёж, но двухстадийный, как у
   Filmbox/Dehancer.
4. **Палитра = extended-gamut matrix (inset crosstalk)** — урок AgX: основной
   носитель «плёночного» hue — 3×3-матрица перед кривой, а не LUT. Отдельный
   палитрный LUT добавляем только если матрицы окажется недостаточно по вкусу.
5. **Мягкая компрессия гамута** к дисплейному — убирает «неон» LED/закатов.
6. **Плёночное ядро заменяет тон-маппер** для режима Film, а не накладывается
   после него.
7. **Зерно (IPOL/Pierre), галация, виньетка** — существующие, без изменений.
   Галацию со временем улучшить: exponential/Lorentzian PSF-свёртка в linear
   light с порогом в стопах (prior art ниже).

## Prior art: что уже решено (исследование 2026-07-12)

Вывод: проблема архитектурно решена несколько раз; изобретать нечего — есть
что адаптировать.

- **flim** (`github.com/bean-mhm/flim`, **AGPLv3** — лицензия совпадает с
  хостом): generic averaged film look, явно «not one stock». Scene-linear
  BT.709 → exposure → tint → extended-gamut matrix → develop negative
  (сигмоида в log2, toe/shoulder/density) → backlight → develop print → cap →
  inverse matrix → midtone-keyed saturation. ~300 строк numpy + GLSL-порт;
  пресеты default/nostalgia/silver. **Основа нашего ядра.**
- **AgX** (Troy Sobotka; дефолт Blender 4.x): inset-матрица → log2 →
  per-channel сигмоида → outset. Sobotka прямо: характер живёт в матрицах,
  форма кривой вторична. Канонический репо **без LICENSE — не копировать**;
  чистые порты: **Godot 4.4** `tonemap.glsl` (~80 строк, MIT), **Bevy**
  `tonemapping_shared.wgsl` (готовый WGSL, MIT/Apache-2.0), **iolite Minimal
  AgX** (MIT, полиномиальная сигмоида + ASC CDL looks).
- **darktable** (GPLv3, §13-совместим с AGPLv3): модуль **sigmoid** —
  grey-anchored log-logistic + AgX-primaries + hyperbolic chroma compression
  (~100 строк); модуль **AgX** — UX-референс: primaries tab
  (attenuation/rotation) как taste-бегунки, авто-пикеры white/black EV.
- **OpenDRT** (jedypod, GPLv3): ratio-preserving tonescale + purity
  compression — эталон exposure-инвариантного DRT; показывает, почему
  per-channel кривые ломают hue.
- **Filmulator** (CarVac, GPLv3): симуляция проявки (developer depletion +
  diffusion) — плёночная тональность/локальный контраст из физики,
  GPU-портируемо. Опция «на потом» для локального контраста; цвет не решает.
- **GEGL negative-darkroom** (LGPLv3+): компактная H&D + dye-density модель
  (~150 строк) — референс «физичного» вкуса.
- **Галация**: exponential/Lorentzian PSF-свёртка в linear light, порог в
  стопах (hotgluebanjo/halation-dctl — без лицензии, берём только идею;
  realbloom — от автора flim).
- **Консенсус коммерческих** (Filmbox, Dehancer, DxO FilmPack): scene-referred
  вход, two-stage negative→print, subtractive-контролы, density-keyed зерно
  (у нас есть), halation как свёртка — наш подход совпадает с индустрией.

**Юридически запрещено**: LUT'ы Kodak 2383/2393 (все циркулирующие копии — без
лицензии, копирайт Kodak), LUT-пакеты ARRI, HaldCLUT-данные RawTherapee/G'MIC
(CC BY-SA + output-referred sRGB — двойной мимо), LUT'ы spektrafilm/vkdt
filmsim (CC BY-SA / no-resale). **Свободны**: энкодинги LogC/Cineon, ACES core
(Apache-2.0), Tony McMapface (MIT/Apache-2.0), Khronos PBR Neutral
(Apache-2.0).

## Лаборатория flim (scratch/)

Рабочее окружение для исследования (2026-07-13):

- `scratch/flim/` — клон `bean-mhm/flim` (AGPLv3) + запечённые LUT'ы
  `flim_{default,nostalgia,silver}.spi3d` (80³, вход log2 [−10,+10], выход
  sRGB). Пекутся за ~15 с на пресет: `cd scratch/flim && ../flim-venv/bin/python main.py`.
- `scratch/flim-venv/` — изолированный venv (numpy, colour-science, joblib,
  pillow).
- `scratch/flim-lab/apply_luts.py` — harness: sRGB → linear → log2-компрессия
  → trilinear sample LUT → сравнительная сетка (original + 3 пресета).
  `--ev` сдвигает экспозицию перед LUT.
- `scratch/flim-lab/out/` — сетки по 5 тестовым изображениям.

### Пресеты flim — параметры

Общее у всех трёх: sigmoid toe (.44, .28), shoulder (.591, .779), окно
log2 [−10, +22/+23], extended gamut scale (1.05, 1.12, 1.045) и rotation
(0.5°, 2°, 0.1°). Отличаются только:

| Параметр | default | nostalgia | silver |
|---|---|---|---|
| pre_exposure (EV) | 4.3 | 5.563 | 3.9 |
| negative exposure / density | 6 / 5 | 5.8 / 5 | 4.7 / 7 |
| print backlight (RGB) | 1,1,1 | .99, 1.1, 1.036 | .9992, .99, 1 |
| print exposure / density | 6 / 27.5 | 6 / 40 | 4.7 / 30 |
| black point | auto | −5 | 0.5 |
| pre / post filter | — | — | холодный @.05 / тёплый @.04 |
| midtone saturation | 1.02 | 1.1 | 1.0 |

Вывод: «вкусовой слой» = 6–8 параметров поверх неизменного скелета —
подтверждает архитектуру flavor-профилей.

### Визуальная оценка (5 сеток, sRGB-вход)

- Поведение мягкое и **консистентное на всех 5 изображениях**: нет неона,
  hue-сдвигов, артефактов клиппинга; красные остаются красными (богаче, но
  без цифрового «пластика»), зелёные не уходят в оливковое.
- default — нейтральный, слегка приглушает; nostalgia — ярче, насыщеннее,
  «живее» (crowd-pleaser); silver — чуть больше контраста, холоднее.
- **Оговорка**: тестовые PNG — display-referred (уже оттонмапленные), flim
  работает в нижней части своего входного окна; toe/shoulder проявятся
  полноценно только на scene-linear RAW. Сетки — демонстрация палитры,
  не финальный тест.

### PoC на реальных RAW (2026-07-13, без корпуса — Go)

- `scratch/flim-lab/apply_luts_raw.py` — ARW → rawpy (linear BT.709, camera
  WB, no auto-bright, half-size) → auto-EV (mean luma → 0.18) → flim LUT →
  сетка neutral/default/nostalgia/silver. A1 II (ILCE-1M2) открывается
  rawpy 0.27 штатно.
- Прогнано 6 случайных RAW из `/Users/someone/Pictures/2025` (906 файлов —
  замена корпусу на этапе PoC): ночной город, котёнок, мост в тумане,
  ярмарка со смешанным светом, солнце в кадре, вольфрам-интерьер.
  Сетки — `scratch/flim-lab/out-raw/`.
- **Результат: все 6 сцен прошли через один набор параметров без ручной
  правки, ни одна не сломалась** — ни неона, ни hue-сдвигов, светила и
  лампы сворачиваются мягко, смешанные температуры разводятся красиво.
  PoC пройден → углубляемся (WGSL-порт, шаг 3).
- Оговорки: look мягкий (усиливается density/backlight/sat); auto-EV по
  среднему груб (4/6 упёрлись в clamp); rawpy ≠ нативный пайплайн
  (демозаик/матрицы) — для оценки трансформа допустимо.
- Корпус по шот-листу переносится со стадии PoC на стадию финальной
  настройки дефолтов (шаг 4).

### Быстрый прототип в RapidRAW (опция)

Запечённые `.spi3d` можно грузить как 3D-текстуру (rgba16f, 80³) и сэмплить
по log2-компрессированному linear — тот же bake-and-sample паттерн, что у
crystal grain. Даёт возможность пощупать flim в приложении **до** порта
математики в WGSL.

## План работ

### Шаг 1. Корпус (пользователь)

25–40 RAW-ов, нарочито перекрывающих весь диапазон. Шот-лист:

- **Экспозиционная серия** — один сюжет (уличный, с деталями в тенях и светах):
  −2, −1, 0, +1, +2 стопа. 5 кадров.
- **Калибровка** — серая карта или ColorChecker при правильной экспозиции,
  дневной свет. 1–2 кадра.
- **Кожа** — при дневном свете, в тени, на golden hour, при лампах накаливания,
  при смешанном свете. 5 кадров.
- **Света** — закат/контровой, небо с облаками, неон/LED ночью, яркие
  точечные источники в кадре. 4–5 кадров.
- **Тени / low-key** — интерьер без вспышки, ночная улица, силуэт; один кадр
  на высоком ISO (6400+), чтобы проверить связку шума сенсора с нашим зерном.
  3 кадра.
- **Насыщенные цвета** — красные объекты, зелень крупно, синее небо,
  жёлтое/оранжевое. 4 кадра.
- **Смешанный свет** — окно + лампы в интерьере. 2 кадра.
- **High-key** — светлый сюжет, много белого. 2 кадра.
- **Свободные** — 3–5 любимых/типовых сюжетов владельца.

RAW only: uncompressed или lossless compressed (14-бит), WB — как снято
(не нормализовать при съёмке). Кадры раскладываются по папкам или именуются
по категориям. Предварительно убедиться, что ARW от A1 II корректно
открывается в текущей сборке RapidRAW (один тестовый кадр).

### Шаг 2. Референсы вкуса (пользователь)

3–5 изображений с целевым «усреднённо-плёночным» видом (свои сканы или чужие
работы). Это мишень для палитры и контраста дефолта.

### Шаг 3. Цветовое ядро

Порт `flim.py` (+ `super_sigmoid.py`) в WGSL: two-stage develop,
extended-gamut matrix с inset/outset как uniform-параметрами, EV-пивот.
Ядро встаёт в GPU-пайплайн до нативного тон-маппера (в scene-referred
linear), заменяя его для режима Film; каркас интеграции — существующий
(см. `docs/film-simulation.md`, «Карта файлов»). Референсы при порте:
Godot/Bevy AgX (MIT) для closed-form деталей, darktable AgX module — для
набора taste-параметров.

### Шаг 4. Итерации по корпусу

Цикл: правка параметров/ядра → рендер всего корпуса → визуальная оценка
(исполнитель просматривает экспорты сам) → фиксация типовых провалов (неон,
сдвиги hue в светах, мёртвые тени, пластиковая кожа) → правка. Владелец
подключается на чекпоинтах вкуса: A/B-варианты дефолта, выбор. Ожидается
3–5 раундов.

### Шаг 5. Бегунки и «вкусовые» профили

Финальный набор бегунков (черновик, уточняется по итогам шага 4):

- Strength — общая сила эффекта.
- Contrast — контраст в density-домене (не сдвигает hue).
- Shoulder — сворачивание светов.
- Toe — подъём/глушение теней.
- Saturation — с кривой спада к краям (не «неонизирует»).
- Warmth — теплота вдоль daylight-локуса (не клиппит света).
- Palette — сила палитрного LUT'а.
- Grain — сила зерна (рендер — существующий IPOL/Pierre).

«Плёнки» = вкусовые слои поверх одного ядра (разные палитрные LUT'ы + сдвиги
дефолтов): нейтральная, тёплая, холодная, ЧБ. Все работают на всём корпусе —
хрупкость пресетов была свойством архитектуры, не палитры.

## Критерии приёмки

- **Один дефолт** даёт приемлемый результат на всём корпусе без движения
  бегунков (90% кадров).
- Бегунки предсказуемы: Contrast не сдвигает цвет, Warmth не клиппит света.
- Нет неона и hue-сдвигов в светах; тени живые; кожа естественна при всех
  типах освещения из корпуса.
- Все «вкусовые» профили проходят корпус целиком.

## Честные ограничения

- Информация, клипнутная на уровне сенсора, не восстанавливается — ядро
  деградирует gracefully (shoulder), но мёртвые пересветы остаются мёртвыми.
- Грубые ошибки WB на съёмке — upstream проблема, не ядра.
- Известное расхождение масштаба зерна превью/экспорт при fit-to-window
  (см. `docs/film-simulation.md`) — оценивать зерно на 100%.

## Реализация (2026-07-13, шаг 3)

**flim в нативном пайплайне.** `tonemapper_mode == 2` в `shader.wgsl` main:
flim считается на `composite_rgb_linear` (scene-referred), завершается
`linear_to_srgb`, downstream (B&W, кривые, зерно) без изменений.
`flim_strength` — mix против legacy-базы той же ветки. `flim_ev` на парсинге
складывается с preset `pre_exposure` (один `exp2` на входе).

**Uniforms:** производные константы пресетов (extend-матрица + inverse,
backlight_ext, white/black cap, develop-параметры, фильтры, midtone sat)
считаются в Rust (`compute_flim_uniforms`) из таблицы пресетов, зеркалящей
`scratch/flim/main.py`; 19 новых полей в хвосте `GlobalAdjustments`
(+192 байта, 16-выравнивание), layout-тест зелёный. Парсинг `flimPreset` /
`flimEv` / `flimStrength` — без секционного гейтинга.

**UI:** новый таб Film (lucide-иконка) в правом switcher'е →
`FilmPanel.tsx`: селектор тон-маппера (Standard/AgX/Flim → существующий
`toneMapper`), preset dropdown (default/nostalgia/silver), EV ±3, Strength.
Любое движение flim-контрола авто-активирует тон-маппер Flim.
i18n en/ru. Старый Krea-модуль (секция Film в Adjustments) не тронут.

**Бегунки Look (2026-07-13):** Contrast (50–150, мультипликатор обеих dye
densities), Saturation (0–200, мультипликатор midtone-keyed sat), Shoulder
(±100 → ±4 стопа верха сигмоидного окна, сворачивание светов), Toe
(±100 → ±0.1 luma сдвиг black cap: + глубже тени, − fade), Warmth
(±100 → ±15% per-channel gain R/B вдоль daylight-локуса, до сигмоиды —
не клиппит). Все параметры, кроме Warmth, фолдятся в Rust при выпеке
uniforms (`compute_flim_uniforms`); Warmth — новый uniform `flim_warmth`
(vec3 в хвосте GlobalAdjustments, +16 байт, layout-тест зелёный).
`flim_check` принимает их аргументами 6–10 для headless-итераций.
Пресеты RapidRAW захватывают все flim-ключи (allow-list `ADJUSTMENT_GROUPS`
→ `COPYABLE_ADJUSTMENT_KEYS` + `toneMapper`).
Замечание по чувствительности: Contrast работает в density-домене обеих
стадий (negative+print), поэтому ×1.3 уже ощутимо темнит средние тона —
это S-кривая, якоренная на black/white cap; Toe на тёмных кадрах крут
(сдвиг black point глобален), рабочий диапазон ±10–20.

**Верификация:**
- `cargo test --lib film_layout_tests` — 3/3; `npm run build` — зелёный.
- Математика сверена с python-референсом flim до f32-точности (все 3 пресета).
