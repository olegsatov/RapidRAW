# Gesture Overlay для жестовой настройки (клавиша A)

## Контекст
В проекте RapidRAW уже реализована жестовая система для регулировки параметров изображения напрямую, без AppleScript и сторонних оверлеев. Первый жест — `gesture_color_balance` на клавишу **A** — управляет:
- одним пальцем/мышью: `temperature` (вертикаль) + `tint` (горизонталь);
- скроллом двумя пальцами: `flimWarmth` (вертикаль) + `flimSaturation` (горизонталь).

Этот документ описывает встроенный визуальный оверлей, который появляется под изображением во время активной жестовой сессии.

## Цель
Дать пользователю визуальную обратную связь о том, какие параметры сейчас меняются, прямо в окне приложения.

## Архитектура

### 1. Состояние — `useGestureStore`
Новый файл: `src/store/useGestureStore.ts`.

```ts
interface GestureOverlayParam {
  label: string;          // i18n-ключ названия пары, например "gesture.overlay.colorBalance"
  axisLabels: [string, string]; // ['temperature', 'tint']
  values: [number, number];
  min: [number, number];
  max: [number, number];
}

interface GestureOverlayState {
  action: string | null;
  isActive: boolean;
  params: GestureOverlayParam[];
}
```

Почему отдельный стор:
- изолирует жестовое состояние от раздутого `useUIStore`;
- упрощает добавление оверлеев для следующих жестов (`S`, `D` и др.).

### 2. Обновления состояния — `useGestureAdjust.ts`
- При старте сессии (`startSession`) — записать `action`, `isActive = true`, начальные `params` из `editor.adjustments`.
- При каждом изменении параметра через `applyDelta` — обновить только соответствующие значения в `useGestureStore`.
- При завершении сессии (`endSession`) — сбросить `isActive` и `action`.

### 3. Компонент оверлея — `GestureOverlay.tsx`
Новый файл: `src/components/ui/GestureOverlay.tsx`.

- Рендерит две панели горизонтально:
  - слева — `temperature` / `tint`;
  - справа — `flimWarmth` / `flimSaturation`.
- Каждая панель содержит:
  - квадратное поле (70×70 px) с перекрестием осей;
  - круглый ползунок, позиционированный по текущим значениям;
  - название пары параметров внизу панели.
- Абсолютное позиционирование внутри контейнера изображения: прижато к низу, центрировано по горизонтали.
- `pointer-events: none`, чтобы не перехватывать ввод.

### 4. Точка встраивания — `Editor.tsx`
Вставить `<GestureOverlay />` внутрь `imageContainerRef`-контейнера (`src/components/panel/Editor.tsx`), поверх `contentRef`/`ImageCanvas`, но ниже спиннера загрузки (z-index ~40).

## Визуальный стиль
- Фон панели: `bg-bg-secondary/70` + `backdrop-blur`.
- Скругление: `rounded-lg`.
- Линии осей: полупрозрачный `text-secondary` / `border-surface`.
- Ползунок: `bg-accent` с белой обводкой и тенью.
- Текст названия панели: `text-text-primary`.
- Размер: фиксированный 70×70 px поле перекрестия на панель для десктопа, в compact/portrait режимах масштабируется пропорционально.

## Поведение
- Оверлей появляется только после `GESTURE_HOLD_DELAY_MS` (150 мс) удержания клавиши — синхронно с началом жестовой сессии.
- Оверлей исчезает мгновенно при отпускании клавиши.
- Короткое нажатие клавиши **A** работает как обычно; оверлей не появляется.
- Если активен модальный диалог, фокус в input или изображение не выбрано — жест не стартует, оверлей не показывается.
- Если `toneMapper !== 'flim'`, сессия `gesture_color_balance` не стартует (уже реализовано в `useGestureAdjust.ts`).
- В полноэкранном режиме оверлей остаётся видимым, если активна сессия.
- Пока активна жестовая сессия, клики мышкой по изображению блокируются (например, чтобы случайный клик не переключал масштаб).

## Scope
**Включает:** оверлей только для `gesture_color_balance` (клавиша **A**). Компонент проектируется так, чтобы добавление оверлеев для `S` и `D` требовало только конфигурации параметров, без изменения архитектуры.

**Не включает:** оверлеи для `gesture_tone_basic` (**S**) и `gesture_lut` (**D**), анимацию fade-in/fade-out, настройки пользователем внешнего вида оверлея.

## Тестирование
- `npm run build` — проверка TypeScript и сборки фронтенда.
- `cargo check` в `src-tauri/` — Rust не затрагивается, но проверка на regressions.
- `npx prettier --check <изменённые файлы>` — форматирование.
- Ручная проверка: удержание **A**, движение мышью/трекпадом, проверка синхронного изменения ползунков; клик по изображению во время жеста не должен переключать масштаб.
