# Gesture Overlay для жестовой настройки (клавиши A, S, D)

## Контекст

В проекте RapidRAW реализована жестовая система для регулировки параметров изображения напрямую, без AppleScript и сторонних оверлеев. Оверлей отображается под изображением во время активной жестовой сессии и показывает, какие параметры сейчас меняются.

Поддерживаются три жеста:

- **A** — `gesture_color_balance`:
  - один палец/мышь: `temperature` (вертикаль) + `tint` (горизонталь);
  - скролл двумя пальцами: `flimWarmth` (вертикаль) + `flimSaturation` (горизонталь).
- **S** — `gesture_tone_basic`:
  - один палец/мышь: `flimEv` (вертикаль) + `flimContrast` (горизонталь);
  - скролл двумя пальцами: `flimShoulder` (вертикаль) + `flimToe` (горизонталь).
- **D** — `gesture_lut`:
  - один палец/мышь: `lutInputOffset` (вертикаль) + `lutInputRange` (горизонталь);
  - скролл двумя пальцами: `lutIntensity` на обе оси.

## Цель

Дать пользователю визуальную обратную связь о текущих параметрах жеста прямо в окне приложения.

## Архитектура

### 1. Состояние — `useGestureStore`

Файл: `src/store/useGestureStore.ts`.

```ts
interface GestureOverlayParam {
  label: string; // переведённое название пары параметров
  axisLabels: [string, string]; // ['temperature', 'tint'] и т.п.
  values: [number, number];
  min: [number, number];
  max: [number, number];
}

interface GestureOverlayState {
  action: string | null;
  isActive: boolean;
  params: GestureOverlayParam[];
}
```

Отдельный стор изолирует жестовое состояние от `useUIStore` и позволяет легко добавлять новые жесты.

### 2. Обновления состояния — `useGestureAdjust.ts`

- При старте сессии (`startSession`) определяется текущий `action` и строится массив `GestureOverlayParam` для соответствующего жеста из `editor.adjustments` и меток `binding.move` / `binding.scroll`.
- `buildOverlayParams()` возвращает по две панели для каждого жеста:
  - **A**: `temperature`/`tint` и `flimWarmth`/`flimSaturation`;
  - **S**: `flimEv`/`flimContrast` (метка `Exp / Cntr`) и `flimShoulder`/`flimToe` (метка `Light / Shad`, ползунок отзеркален по обеим осям через `invert: [true, true]`);
  - **D**: `lutInputOffset`/`lutInputRange` (один палец) и `lutIntensity` на скролле (метка `LUT Intensity`, ползунок привязан к вертикальной оси, `orientation: 'vertical'`).
- При каждом изменении параметра через `applyDelta` вызывается `updateOverlayValues`, который обновляет только `values` в сторе.
- При завершении сессии (`endSession`) сбрасывается `isActive` и `action`.

### 3. Компонент оверлея — `GestureOverlay.tsx`

Файл: `src/components/ui/GestureOverlay.tsx`.

- Рендерит панели горизонтально, центрированными по нижнему краю контейнера изображения.
- Каждая панель содержит:
  - квадратное поле 70×70 px с перекрестием осей;
  - круглый ползунок, позиционированный по текущим значениям;
  - название пары параметров внизу панели.
- `pointer-events: none`, чтобы не перехватывать ввод.

### 4. Точка встраивания — `Editor.tsx`

`<GestureOverlay />` вставлен внутрь `imageContainerRef`-контейнера (`src/components/panel/Editor.tsx`) поверх `contentRef`/`ImageCanvas`, но ниже спиннера загрузки (z-index ~40).

## Визуальный стиль

- Фон панели: `bg-bg-secondary/25` + `backdrop-blur-sm`.
- Скругление: `rounded-lg`.
- Линии осей: `bg-text-secondary/20`.
- Ползунок: `bg-accent` с белой обводкой и тенью.
- Текст названия панели: `text-text-primary/40 text-[10px]`.
- Размер: фиксированный 70×70 px поле перекрестия.

## Поведение

- Оверлей появляется после `GESTURE_HOLD_DELAY_MS` (150 мс) удержания клавиши — синхронно с началом жестовой сессии.
- Короткое нажатие клавиши работает как обычно; оверлей не появляется.
- Оверлей исчезает мгновенно при отпускании клавиши.
- Если активен модальный диалог, фокус в input или изображение не выбрано — жест не стартует, оверлей не показывается.
- `gesture_color_balance` стартует только при `toneMapper === 'flim'`.
- Все три жеста отображаются в настройках хоткеев в отдельном разделе **Gestures** и могут быть переназначены на другие клавиши.
- В полноэкранном режиме оверлей остаётся видимым, если активна сессия.
- Пока активна жестовая сессия, клики мышкой по изображению блокируются (`handleClick` в `Editor.tsx` возвращает управление, если `isGestureActive`).
- Во время сессии обрабатываются только клавиша жеста и `Escape` (завершает сессию); остальные клавиши не блокируются, чтобы не мешать системным сочетаниям.
- Потеря фокуса окна (`blur`) или сворачивание вкладки (`visibilitychange`) немедленно завершает сессию и восстанавливает курсор.
- Двойной клик левой кнопкой / одним пальцем на трекпаде сбрасывает параметры первого оверлея к дефолтным значениям.
- Правый клик / тап двумя пальцами по трекпаду (`contextmenu`/`auxclick`) сбрасывает параметры второго оверлея к дефолтным значениям.

## Scope

**Включает:** встроенные оверлеи для `gesture_color_balance` (**A**), `gesture_tone_basic` (**S**) и `gesture_lut` (**D**).

**Не включает:** анимацию fade-in/fade-out, настройки внешнего вида оверлея пользователем, оверлеи для возможных будущих жестов.

## Тестирование

- `npm run build` — проверка TypeScript и сборки фронтенда.
- `cargo check` в `src-tauri/` — Rust не затрагивается, но проверка на regressions.
- `npx prettier --check <изменённые файлы>` — форматирование.
- Ручная проверка: удержание **A**/**S**/**D**, движение мышью/трекпадом, проверка синхронного изменения ползунков; клик по изображению во время жеста не должен переключать масштаб.
