# LUT-панель: компактный режим, папки и избранное

## Контекст

LUT-панель сейчас живёт в левой колонке на отдельной вкладке рядом с пресетами. Она показывает LUT-ы плиткой (1–2 в ряд), при клике под выбранной плиткой открывается панель с ползунками. Пресеты имеют компактный список с папками; LUT-ы — нет. Цель — привести организацию LUT-ов к тому же UX, что и у пресетов, максимально переиспользовав их код и стили.

## Цели

1. Добавить переключатель вида LUT-панели: **компактный** (как список пресетов) и **развёрнутый** (текущая плиточная сетка).
2. Добавить **виртуальные папки** для LUT по аналогии с папками пресетов.
3. Добавить **избранные LUT**, которые используются в оверлее быстрого переключения по клавише `D`.
4. Переиспользовать существующие компоненты пресетов и модалки, чтобы не дублировать сущности.

## Не-цели

- Физические подпапки на диске в директории `luts/`.
- Изменение панели пресетов или её поведения.
- Изменение математики применения LUT.

## Архитектура

### Модель данных

Расширяем `AppSettings` (Rust + frontend type) тремя новыми полями:

```ts
interface LutFolder {
  id: string;
  name: string;
  children: string[]; // LUT file paths
}

interface AppSettings {
  // ...existing fields...
  lutFolders: LutFolder[];
  lutOrder: string[];       // порядок LUT в корне
  lutFavorites: string[];   // избранные пути
}
```

LUT идентифицируются по файловому пути (`path`), потому что имена могут дублироваться.

### Store

Новый `src/store/useLutStore.ts`:

- Хранит список LUT с диска (`LutEntry[]`).
- Хранит дерево папок и порядок элементов.
- Хранит множество избранных путей.
- Предоставляет операции:
  - `addFolder(name)`
  - `renameFolder(id, name)`
  - `deleteFolder(id, moveChildrenToRoot?: boolean)`
  - `moveLutToFolder(path, folderId | null)`
  - `reorderLut(oldIndex, newIndex)` / `reorderFolderLut(folderId, oldIndex, newIndex)`
  - `toggleFavorite(path)`
- Сохраняет изменения в `AppSettings` с debounce 500 мс, как это делает `usePresetStore`.

### Режимы отображения

Режим хранится в `AppSettings` (или `useUIStore`), чтобы выбор сохранялся между сессиями.

- **Развёрнутый режим** — текущее поведение: responsive grid (`grid-cols-1` / `grid-cols-2`), квадратные превью, имя LUT под плиткой, бейдж хоткея, inline `LutDetailPanel` под выбранным элементом.
- **Компактный режим** — список строк по образцу `PresetItemDisplay`: маленькая превью слева, имя + бейдж хоткея справа. Выбранная строка также разворачивается inline и показывает `LutDetailPanel`.

### Папки

- Папки рендерятся заголовком с иконкой папки, именем, счётчиком детей и стрелкой раскрытия — по образцу preset folders.
- Дети папки отображаются с отступом `ml-5 pl-4 border-l-[1.5px] border-border-color/50`.
- Состояние раскрытых папок хранится локально в `Set` (не персистируется), как в пресетах.
- Drag-and-drop:
  - LUT можно перетаскивать в папку и обратно в корень.
  - Внутри папки и в корне можно менять порядок.
  - Используем `@dnd-kit/core` по тому же паттерну, что и в `PresetsBrowser`, но ключом выступает `path` LUT вместо `id` пресета.

### Контекстное меню

Для LUT:
- Configure LUT (переименовать + хоткей) — существующая модалка.
- Add to folder → подменю со списком папок + "New folder...".
- Remove from folder (показывается только внутри папки).
- Mark as favorite / Remove from favorites.
- Delete LUT.

Для папки:
- Rename folder — переиспользуем `RenameFolderModal`.
- Delete folder → подтверждение + опция "переместить LUT в корень".

Для фона панели:
- Create folder — переиспользуем `CreateFolderModal`.
- Compact / Expanded view.

### Избранное и D-оверлей

- У каждого LUT в списке — иконка звезды (в строке или в контекстном меню). Клик переключает избранное.
- Оверлей быстрого выбора LUT по клавише `D` (`useGestureAdjust.ts`) использует:
  - избранные LUT, если их больше 0;
  - иначе весь плоский список LUT.
- Избранные хранятся в `AppSettings.lutFavorites`.

## Поведение при краевых случаях

- LUT есть на диске, но отсутствует в `lutOrder` — показываем в конце списка.
- LUT есть в папке/порядке, но отсутствует на диске — показываем серым; при клике предлагаем удалить из папки.
- Пустая папка — отображается пустой; удаление папки без детей — без подтверждения.
- Удаление непустой папки — подтверждение с опцией переместить LUT-ы в корень.
- Удалённый LUT, который был в избранном — удаляется из избранного при загрузке store.
